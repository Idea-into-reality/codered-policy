자주 묻는 질문

기기를 바꾸면 기록은 어떻게 옮기나요?
설정 → 백업 내보내기로 암호화 파일을 저장한 뒤, 새 기기에서 설정 → 백업에서 복원을 하면 됩니다. 서버에 저장하지 않으므로 백업 없이 앱을 삭제하면 기록을 되살릴 수 없습니다.

프리미엄을 다시 받으려면?
프리미엄 화면의 '구매 복원'을 누르면 같은 스토어 계정으로 구매한 프리미엄이 복원됩니다.
